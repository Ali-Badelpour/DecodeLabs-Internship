# 🛡️ System Vulnerability Checklist

## 📌 Project Overview
**Project**: System Vulnerability Checklist  
**Domain**: Cyber Security  
**Week**: 4  
**Batch**: 2026  
**Organization**: DecodeLabs  

This project is a Windows system vulnerability scanner and audit tool. It checks:
- Firewall status
- Disk encryption (BitLocker)
- Admin group memberships
- Guest account status
- Windows update status
- Screen lock timeout
- Installed software (Shadow IT detection)

---

## 🎯 Objectives
- ✅ Perform a security audit on Windows 11
- ✅ Identify at least 3 vulnerabilities
- ✅ Document findings professionally
- ✅ Remediate vulnerabilities
- ✅ Provide proof of hardened state

---

## 🛠️ Features
- ✅ Automated vulnerability scanning
- ✅ Professional Markdown report generation
- ✅ Risk level classification (Critical/High/Medium/Low)

- ✅ Hardened state verification
