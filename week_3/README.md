# 🎣 Phishing Awareness Analysis
## 📌 Project Overview
**Project**: Phishing Awareness Analysis  
**Domain**: Cyber Security  
**Week**: 3  
**Batch**: 2026  
**Organization**: DecodeLabs  

This project is a comprehensive phishing email analysis tool that identifies red flags, suspicious links, and cognitive triggers in emails. It helps bridge the gap between technical security and human psychology by demonstrating how attackers exploit trust, urgency, and authority.

## 🎯 Objectives
- ✅ Identify phishing attempts through systematic analysis
- ✅ Recognize suspicious links and keywords
- ✅ List red flags found in phishing messages
- ✅ Explain why messages are unsafe
- ✅ Provide triage recommendations (Safe/Suspicious/Malicious)
---
## 🛠️ Features
- ✅ **Sender Analysis**: Detects domain spoofing, display name manipulation
- ✅ **Content Analysis**: Identifies urgency, fear, authority, greed triggers
- ✅ **Link Analysis**: Detects suspicious domains, URL shorteners, lookalike URLs
- ✅ **Risk Scoring**: Calculates risk score (0-100) with severity levels
- ✅ **Triage Recommendations**: Clear actions (BLOCK, WARN, CAUTION, CLOSE)
- ✅ **Sample Library**: Built-in phishing examples for training
- ✅ **Cognitive Trigger Detection**: Identifies psychological manipulation
